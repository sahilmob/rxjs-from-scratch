# My Signals

A learning implementation of reactive programming patterns inspired by RxJS.

## Purpose

This library is built for educational purposes to understand reactive programming concepts by implementing them from scratch.

## Getting Started

```bash
# Install dependencies
npm install

# Run tests
npm test

# Run tests in watch mode
npm run test:watch
```

## Structure

- `src/core/` - Core Observable, Subscriber, and Subscription implementations
- `src/observable/` - Observable creation functions (of, from, interval, etc.)
- `src/operators/` - Pipeable operators (map, filter, merge, etc.)
- `src/subjects/` - Subject implementations
- `tests/` - Test suites for all implementations
